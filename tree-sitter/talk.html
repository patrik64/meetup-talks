Incremental parsing with Tree-sitter

Tree-sitter

a library for parsing source code

  • https://tree-sitter.github.io
  • https://github.com/tree-sitter/tree-sitter
  • https://en.wikipedia.org/wiki/Tree-sitter_(parser_generator)

author: Max Brunsfeld

  • https://github.com/maxbrunsfeld

Tree-sitter is

  • parser generator tool
  • incremental parser library
  • query engine

with Tree-sitter you can

  • generate a syntax tree
  • ask questions about the tree

Tree-sitter is used in

  • Zed
  • Emacs
  • Neovim
  • Helix
  • Github
  • ...

Tree-sitter is based on

  • Practical Algorithms for Incremental Software Development Environments Tim A. Wagner 1998
  • LR / GLR parsing
  • https://en.wikipedia.org/wiki/LR_parser
  • https://en.wikipedia.org/wiki/GLR_parser

Tree-sitter parts

  • CLI - Rust
  • parser generator - Rust + Node
  • runtime - C
  • bindings

to create a new parser using Tree-sitter

  • create grammar.js file

output

  • grammar.json
  • node-types.json
  • parser.c
